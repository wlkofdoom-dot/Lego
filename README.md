# Lego: My Personal Docker Setup

This is my personal Docker setup, which I am Tweaking so that I can deploy it on any system at any time with zero friction. I thought I'd share my progress for anyone else who wants a simple, working setup without dealing with endless technical headaches.

---

## 🛠️ How to Use This

If you want to try this setup on your own computer, **you must follow the steps in order, going from 1 to 10**. Each step relies on the previous ones to work properly.

---

## 🔒 Personal Information Cleared

I used AI to scrub and sanitize personal network names, private passwords, and specific IP addresses from all of these files so they are safe to share publicly. 

If you use this setup yourself:
* Update the IP addresses i to match your own home network.
* Put your own passwords into the login files.
* Adjust folder locations if your hard drives use different names.
